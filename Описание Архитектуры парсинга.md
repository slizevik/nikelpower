Образ готового проекта
1. Существуют два бизнес процесса - загрузка документов в формате pdf, dox, pptx
для загрузки

**Пропиши здесь термины:**
Термины:
- документ - файл, 
- изображение = рисунок = картинка

Алгоритм процесса парсинга документа следующий:
1. Загруженный документ переводится в pdf формат с помощью libreoffice. Скачай libreoffice с gocker hub, пропиши в dockerfile backend все необходимые зависимости. необходимо встроить в архитектуру приложения без конфликтов. проверь согласованность всех используемых библиотек;
2. Далее пропиши код для libreoffice - в коде необходимо перевести документ в формат pdf. если документ изначально pdf формата - пропускаем шаг с конвертацией в pdf.
3. Код libreoffice должен вернуть парсеру pdf документ;
4. Далее должна производится обработка самого документа. Алгоритм следующий:
	1. В документе отдельно извлекаются весь текст документа и все изображения. Дальнейшая работа производится только с изображениями;
	2. Каждое изображение в документе заменяется на специальный технический текст, который обозначает уникальный ID изображения;
	3. Все изображения, последовательно, должны передаваться в LLM Qwen3-VL через API. Составь промпт, в котором пропиши, чтобы модель обязательно вернула в ответе следующее:
		- указание типа картинки (график, таблица или любая другая категория);
		- если это график или таблица, то проведи подробный анализ и оставь только ключевую информацию о графике, полезную с точки зрения материаловедения;
		- для всех остальных категорий модель должна определить, поможет ли это для анализа документа, если да, то описывает изображение, если нет, то пишет что изображение бесполезно.
	4. Заменяются на уникальный ID, по которому в дальнейшем будет сформулировано описание изображения. Сами изображения из файла передаются в любом формате (jpeg, png) в Qwen 3- VL через API ключ.
далее документ переходит к модели qwen3-VL. модель просматривает загруженные рисунки и формирует текстовое описание картинки. Описание должно включать:
- указание типа картинки (график, таблица или любая другая категория);
- содержащиеся там значения (укажи только те, которые могут содержать полезную информацию для анализа)
- подробный анализ картинки с точки зрения материаловедения
Итоговый результат должно быть соответствие ключ-значение. вместо картинки ключ
